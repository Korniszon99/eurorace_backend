    Jak dodać pary uczestników

    Każda para ma jedno konto logowania do aplikacji mobilnej. W środku para ma dwóch członków (TeamMember), których lokalizacje mogą być śledzone osobno po wyborze w aplikacji.

    Sposób zalecany: import CSV Użyj przycisku Import CSV kont par u góry listy. To najszybsza metoda przed startem wyścigu.
    Sposób ręczny Kliknij Dodaj parę, wybierz wyścig, utwórz lub przypisz użytkownika Django i uzupełnij dane członków w sekcji poniżej formularza.
    Po imporcie Przekaż parom login i hasło. Token API tworzy się automatycznie — aplikacja loguje się loginem i hasłem pary.
    Szczegółowy opis kolumn CSV i przykładowy plik znajdziesz na stronie importu CSV.
