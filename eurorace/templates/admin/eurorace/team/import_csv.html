Import kont par z pliku CSV

Ten import tworzy lub aktualizuje konta par: użytkownika Django, token API, rekord pary, dwóch członków oraz przypisuje wszystkie istniejące zadania do nowych kont.

Krok po kroku

  1. Upewnij się, że wyścig jest już utworzony i oznaczony jako aktywny.
  2. Przygotuj plik CSV w kodowaniu UTF-8 (Excel: „CSV UTF-8”).
  3. Wybierz wyścig i wgraj plik poniżej.
  4. Po imporcie zapisz wygenerowane hasła — nie będą ponownie wyświetlone.
  5. Przekaż parom login i hasło przed startem wydarzenia.

Obsługiwane kolumny

Kolumna Wymagana Opis
username / login Tak Login pary do aplikacji mobilnej. Unikalny w całym systemie.
password Nie Hasło pary. Jeśli puste, system wygeneruje losowe 12-znakowe hasło.
team_name / display_name Nie Nazwa wyświetlana pary na live trackerze i w aplikacji.
bib_number / number Nie Numer startowy pary (np. 42). Unikalny w ramach wyścigu.
contact_email / email Nie Kontakt do pary — trafia też do konta użytkownika Django.
member_1_name / member1 Zalecana Imię i nazwisko pierwszego uczestnika pary.
member_2_name / member2 Zalecana Imię i nazwisko drugiego uczestnika pary.
member_1_email, member_2_email Nie Opcjonalne adresy e-mail członków.
member_1_phone, member_2_phone Nie Opcjonalne numery telefonów członków.

Przykładowy plik CSV

username,password,team_name,bib_number,contact_email,member_1_name,member_2_name,member_1_email,member_2_email
para_01,tajne_haslo_01,Team Alpha,1,alpha@example.com,Jan Kowalski,Anna Nowak,jan@example.com,anna@example.com
para_02,,Team Beta,2,beta@example.com,Piotr Wiśniewski,Maria Zielińska,,
