Instrukcja konfiguracji wyścigu

  1. Nazwa — widoczna dla organizatora i w danych API (np. „Eurorace PW 2026”).
  2. Daty — opcjonalne, ale pomocne przy planowaniu i archiwizacji edycji.
  3. Miejsce docelowe — kliknij na mapie punkt mety wyścigu. Para widzi go w aplikacji mobilnej jako punkt orientacyjny.
  4. Nazwa miejsca docelowego — etykieta na mapie live (np. „Santorini”, „Lizbona”).
  5. Aktywny — zaznacz dla bieżącej edycji. Meta i import CSV domyślnie używają aktywnego wyścigu.
Jeśli zmieniasz metę w trakcie wydarzenia, uczestnicy zobaczą nową lokalizację po odświeżeniu mapy w aplikacji.
